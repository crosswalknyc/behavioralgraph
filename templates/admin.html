📊 Gen Pop Cache

                

                

                    

                        Forces server workers to reload the canonical Gen Pop baseline from S3 for profile indexing.
                    

                    

                        
                        
                    

                

            


            
            

                

                    
🗂️ Profile Selector Cache

                

                

                    

                        Rebuilds the profile-selector cache from a full scan of every CSV at the root
                        of s3://dashboard-inputs/. Use this when a newly uploaded profile
                        isn't showing up in the sidebar selector. Typically takes 30 seconds to a few
                        minutes depending on how many profiles are in the bucket.
                    

                    

                        
                        
                    

                    

                        

                            

                        

                        

                    

                

            


            
            

                

                    
🧮 Category Norms

                

                

                    

                        Pre-computes a sample-size-weighted average BP across every profile in each
                        category. Used by the dashboard's Data Cuts → Show Category Norm toggle so the
                        norm appears alongside prior data cuts and Gen Pop without a slow on-demand calc.
